# echecker Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Android app + home-screen widget that shows whether power is on right now for the user's selected queue, based on outage schedules parsed from the public Telegram channel `Zaporizhzhyaoblenergo_news`.

**Architecture:** Single `app` module, no backend. `ChannelFetcher` scrapes `https://t.me/s/<channel>` (Jsoup), `ScheduleParser` turns post text into `Schedule`, `ScheduleRepository` stores the newest schedule per date in Room. A periodic `SyncWorker` keeps data fresh; a Glance widget renders the status computed by the pure `PowerStatusCalculator` + `StatusFormatter`, and re-renders itself via an AlarmManager alarm at the next status change. A single Compose screen offers queue selection, today/tomorrow, and history.

**Tech Stack:** Kotlin 2.1.21, AGP 8.13.2, Gradle 8.14, Jetpack Compose (BOM 2025.06.01), Glance 1.1.1, WorkManager 2.10.2, Room 2.7.2 (KSP), DataStore 1.1.7, OkHttp 4.12.0, Jsoup 1.18.3, JUnit 4, Robolectric 4.14.1.

Spec: `docs/superpowers/specs/2026-11-12-echecker-design.md`

## Global Constraints

- Package / applicationId: `ua.echecker`. `minSdk = 26`, `compileSdk = 36`, `targetSdk = 36`, JVM target 17.
- Channel: `Zaporizhzhyaoblenergo_news`, page URL `https://t.me/s/Zaporizhzhyaoblenergo_news`, older pages `?before=<postId>`.
- All time math in zone `Europe/Kyiv` (fallback `Europe/Kiev` on old tzdata) — via `KyivTime.ZONE`, never `ZoneId.systemDefault()`.
- For one date, the schedule from the post with the **largest postId** wins.
- Queues: 1.1 … 6.2 (group 1..6, sub 1..2). `24:00` = minute 1440.
- Periodic sync every 30 min with network constraint; backfill 30 days, max 20 pages; stale note when last successful sync > 3 h.
- UI/widget copy is Ukrainian, exactly as written in this plan.
- No backend, no Telegram login, no notifications.
- If a dependency version fails to resolve, bump to the nearest available version; keep Kotlin, KSP (`<kotlin>-x.y.z`) and the Compose compiler plugin aligned.

```kotlin
package ua.echecker.domain

import java.time.LocalDate
import java.time.ZoneId
import java.util.Locale

data class Queue(val group: Int, val sub: Int) : Comparable<Queue> {
    init {
        require(group in 1..6 && sub in 1..2) { "Invalid queue $group.$sub" }
    }

    override fun toString() = "$group.$sub"

    override fun compareTo(other: Queue) = compareValuesBy(this, other, Queue::group, Queue::sub)

    companion object {
        val ALL: List<Queue> = (1..6).flatMap { g -> (1..2).map { s -> Queue(g, s) } }

        fun parse(s: String): Queue? {
            val parts = s.trim().split(".")
            if (parts.size != 2) return null
            val g = parts[0].toIntOrNull() ?: return null
            val sub = parts[1].toIntOrNull() ?: return null
            return if (g in 1..6 && sub in 1..2) Queue(g, sub) else null
        }
    }
}

/** Minutes of day, 0..1440 (1440 = 24:00). */
data class Interval(val startMinute: Int, val endMinute: Int) {
    init {
        require(startMinute in 0..1440 && endMinute in 0..1440 && startMinute < endMinute) {
            "Invalid interval $startMinute..$endMinute"
        }
    }

    fun format() = "${formatMinute(startMinute)}–${formatMinute(endMinute)}"

    companion object {
        fun formatMinute(m: Int): String = String.format(Locale.ROOT, "%02d:%02d", m / 60, m % 60)

        fun merge(list: List<Interval>): List<Interval> {
            val result = mutableListOf<Interval>()
            for (i in list.sortedBy { it.startMinute }) {
                val last = result.lastOrNull()
                if (last != null && i.startMinute <= last.endMinute) {
                    result[result.lastIndex] = Interval(last.startMinute, maxOf(last.endMinute, i.endMinute))
                } else {
                    result += i
                }
            }
            return result
        }
    }
}

data class Schedule(val date: LocalDate, val queues: Map<Queue, List<Interval>>) {
    fun intervalsFor(q: Queue): List<Interval> = queues[q].orEmpty()
}

object KyivTime {
    val ZONE: ZoneId = runCatching { ZoneId.of("Europe/Kyiv") }.getOrElse { ZoneId.of("Europe/Kiev") }
}
```

```kotlin
package ua.echecker.domain

import java.time.LocalDate

object ScheduleParser {
    private val DATE = Regex("""Графік\s+відключен\S*\s+на\s+(\d{2})\.(\d{2})\.(\d{4})""")
    private val QUEUE = Regex("""Черга\s+(\d)\.(\d)""")
    private val INTERVAL = Regex("""[зЗ]\s+(\d{1,2}):(\d{2})\s+до\s+(\d{1,2}):(\d{2})""")

    fun parse(text: String): Schedule? {
        val dm = DATE.find(text) ?: return null
        val (d, m, y) = dm.destructured
        val date = runCatching { LocalDate.of(y.toInt(), m.toInt(), d.toInt()) }.getOrNull() ?: return null

        val raw = linkedMapOf<Queue, MutableList<Interval>>()
        var current: Queue? = null
        for (line in text.lines()) {
            val qm = QUEUE.find(line)
            if (qm != null) {
                current = Queue.parse("${qm.groupValues[1]}.${qm.groupValues[2]}")
                continue
            }
            val queue = current ?: continue
            for (im in INTERVAL.findAll(line)) {
                val (sh, sm, eh, em) = im.destructured
                val start = sh.toInt() * 60 + sm.toInt()
                val end = eh.toInt() * 60 + em.toInt()
                if (start in 0..1440 && end in 0..1440 && start < end) {
                    raw.getOrPut(queue) { mutableListOf() } += Interval(start, end)
                }
            }
        }
        return Schedule(date, raw.mapValues { Interval.merge(it.value) })
    }
}
```

```kotlin
package ua.echecker.domain

import java.time.ZonedDateTime

sealed interface PowerStatus {
    /** Power is on. [nextOffAt] = start of next outage, or null if none scheduled (today/tomorrow). */
    data class On(val nextOffAt: ZonedDateTime?) : PowerStatus
    data class Off(val nextOnAt: ZonedDateTime) : PowerStatus
    data object NoScheduleToday : PowerStatus
    data object NoData : PowerStatus
    data object QueueNotSelected : PowerStatus
}

object PowerStatusCalculator {
    private data class Span(val start: ZonedDateTime, val end: ZonedDateTime)

    fun calculate(
        today: Schedule?,
        tomorrow: Schedule?,
        queue: Queue?,
        now: ZonedDateTime,
        hasSynced: Boolean,
    ): PowerStatus {
        if (queue == null) return PowerStatus.QueueNotSelected
        if (today == null) return if (hasSynced) PowerStatus.NoScheduleToday else PowerStatus.NoData

        val spans = (spansOf(today, queue) + (tomorrow?.let { spansOf(it, queue) } ?: emptyList()))
            .sortedBy { it.start.toInstant() }
        val merged = mutableListOf<Span>()
        for (s in spans) {
            val last = merged.lastOrNull()
            if (last != null && !s.start.isAfter(last.end)) {
                if (s.end.isAfter(last.end)) merged[merged.lastIndex] = last.copy(end = s.end)
            } else {
                merged += s
            }
        }

        merged.firstOrNull { !now.isBefore(it.start) && now.isBefore(it.end) }
            ?.let { return PowerStatus.Off(it.end) }
        return PowerStatus.On(merged.firstOrNull { it.start.isAfter(now) }?.start)
    }

    private fun spansOf(s: Schedule, q: Queue): List<Span> {
        val midnight = s.date.atStartOfDay()
        return s.intervalsFor(q).map {
            Span(
                midnight.plusMinutes(it.startMinute.toLong()).atZone(KyivTime.ZONE),
                midnight.plusMinutes(it.endMinute.toLong()).atZone(KyivTime.ZONE),
            )
        }
    }
}
```

```kotlin
package ua.echecker.domain

import java.time.Duration
import java.time.Instant
import java.time.LocalTime
import java.time.ZonedDateTime
import java.time.format.DateTimeFormatter

data class StatusText(val title: String, val subtitle: String?, val staleNote: String?)

object StatusFormatter {
    private val TIME = DateTimeFormatter.ofPattern("HH:mm")
    private val DATE_TIME = DateTimeFormatter.ofPattern("dd.MM HH:mm")
    private val STALE_AFTER: Duration = Duration.ofHours(3)

    fun format(status: PowerStatus, now: ZonedDateTime, lastSyncAt: Instant?): StatusText {
        val stale = lastSyncAt
            ?.takeIf { Duration.between(it, now.toInstant()) > STALE_AFTER }
            ?.let {
                val t = it.atZone(now.zone)
                if (t.toLocalDate() == now.toLocalDate()) "оновлено о ${TIME.format(t)}"
                else "оновлено ${DATE_TIME.format(t)}"
            }
        return when (status) {
            is PowerStatus.On -> StatusText(
                "💡 Світло є",
                status.nextOffAt?.let { "вимкнуть ${at(it, now)}" } ?: "відключень більше нема",
                stale,
            )
            is PowerStatus.Off -> StatusText("🌑 Світла нема", "увімкнуть ${at(status.nextOnAt, now)}", stale)
            PowerStatus.NoScheduleToday -> StatusText("Відключень не заплановано", null, stale)
            PowerStatus.NoData -> StatusText("Немає даних", "відкрийте застосунок", null)
            PowerStatus.QueueNotSelected -> StatusText("Оберіть чергу", null, null)
        }
    }

    private fun at(t: ZonedDateTime, now: ZonedDateTime): String {
        val local = t.withZoneSameInstant(now.zone)
        val tomorrow = now.toLocalDate().plusDays(1)
        return when {
            local.toLocalDate() == now.toLocalDate() -> "о ${TIME.format(local)}"
            local.toLocalDate() == tomorrow && local.toLocalTime() == LocalTime.MIDNIGHT -> "о 24:00"
            else -> "завтра о ${TIME.format(local)}"
        }
    }
}
```

```kotlin
package ua.echecker.data

import kotlinx.coroutines.Dispatchers
import kotlinx.coroutines.withContext
import okhttp3.OkHttpClient
import okhttp3.Request
import org.jsoup.Jsoup
import org.jsoup.nodes.TextNode
import java.io.IOException
import java.time.Instant
import java.time.OffsetDateTime

data class RawPost(val id: Long, val publishedAt: Instant, val text: String)

interface PostSource {
    /** Returns posts sorted by id ascending. [before] = load posts older than this id. */
    suspend fun fetch(before: Long? = null): List<RawPost>
}

class ChannelFetcher(
    private val client: OkHttpClient,
    private val channel: String = "Zaporizhzhyaoblenergo_news",
) : PostSource {

    override suspend fun fetch(before: Long?): List<RawPost> = withContext(Dispatchers.IO) {
        val url = "https://t.me/s/$channel" + (before?.let { "?before=$it" } ?: "")
        val request = Request.Builder()
            .url(url)
            .header("User-Agent", "Mozilla/5.0 (Linux; Android) echecker")
            .build()
        client.newCall(request).execute().use { resp ->
            if (!resp.isSuccessful) throw IOException("HTTP ${resp.code} for $url")
            parseHtml(resp.body?.string() ?: throw IOException("Empty body for $url"))
        }
    }

    companion object {
        fun parseHtml(html: String): List<RawPost> =
            Jsoup.parse(html).select("div.tgme_widget_message[data-post]").mapNotNull { msg ->
                val id = msg.attr("data-post").substringAfterLast('/').toLongOrNull()
                    ?: return@mapNotNull null
                val textEl = msg.selectFirst(".tgme_widget_message_text.js-message_text")
                    ?: return@mapNotNull null
                val time = msg.selectFirst("time[datetime]")?.attr("datetime")
                    ?: return@mapNotNull null
                val publishedAt = runCatching { OffsetDateTime.parse(time).toInstant() }.getOrNull()
                    ?: return@mapNotNull null
                textEl.select("br").forEach { it.replaceWith(TextNode("\n")) }
                RawPost(id, publishedAt, textEl.wholeText())
            }.sortedBy { it.id }
    }
}
```

```kotlin
package ua.echecker.data.db

import androidx.room.Dao
import androidx.room.Insert
import androidx.room.OnConflictStrategy
import androidx.room.Query
import androidx.room.Transaction
import kotlinx.coroutines.flow.Flow

@Dao
abstract class ScheduleDao {
    @Query("SELECT postId FROM schedules WHERE date = :date")
    protected abstract suspend fun postIdFor(date: String): Long?

    @Insert(onConflict = OnConflictStrategy.REPLACE)
    protected abstract suspend fun insertSchedule(schedule: ScheduleEntity)

    @Query("DELETE FROM intervals WHERE date = :date")
    protected abstract suspend fun deleteIntervals(date: String)

    @Insert
    protected abstract suspend fun insertIntervals(intervals: List<IntervalEntity>)

    /** Stores the schedule only if no schedule from a newer-or-equal post exists. */
    @Transaction
    open suspend fun upsertIfNewer(schedule: ScheduleEntity, intervals: List<IntervalEntity>): Boolean {
        val existing = postIdFor(schedule.date)
        if (existing != null && existing >= schedule.postId) return false
        deleteIntervals(schedule.date)
        insertSchedule(schedule)
        insertIntervals(intervals)
        return true
    }

    @Transaction
    @Query("SELECT * FROM schedules WHERE date = :date")
    abstract suspend fun get(date: String): ScheduleWithIntervals?

    @Transaction
    @Query("SELECT * FROM schedules WHERE date = :date")
    abstract fun observe(date: String): Flow<ScheduleWithIntervals?>

    @Transaction
    @Query("SELECT * FROM schedules WHERE date BETWEEN :from AND :to ORDER BY date DESC")
    abstract fun observeRange(from: String, to: String): Flow<List<ScheduleWithIntervals>>
}
```

```kotlin
package ua.echecker.data

import kotlinx.coroutines.flow.Flow
import kotlinx.coroutines.flow.map
import ua.echecker.data.db.IntervalEntity
import ua.echecker.data.db.ScheduleDao
import ua.echecker.data.db.ScheduleEntity
import ua.echecker.data.db.ScheduleWithIntervals
import ua.echecker.domain.Interval
import ua.echecker.domain.Queue
import ua.echecker.domain.Schedule
import ua.echecker.domain.ScheduleParser
import java.time.Instant
import java.time.LocalDate

class ScheduleRepository(
    private val dao: ScheduleDao,
    private val source: PostSource,
) {
    suspend fun sync() {
        save(source.fetch(null))
    }

    suspend fun backfill(since: Instant, maxPages: Int = 20) {
        var before: Long? = null
        repeat(maxPages) {
            val posts = source.fetch(before)
            if (posts.isEmpty()) return
            save(posts)
            if (posts.minOf { it.publishedAt } < since) return
            before = posts.minOf { it.id }
        }
    }

    suspend fun get(date: LocalDate): Schedule? = dao.get(date.toString())?.toDomain()

    fun observe(date: LocalDate): Flow<Schedule?> = dao.observe(date.toString()).map { it?.toDomain() }

    fun observeRange(from: LocalDate, to: LocalDate): Flow<List<Schedule>> =
        dao.observeRange(from.toString(), to.toString()).map { list -> list.map { it.toDomain() } }

    private suspend fun save(posts: List<RawPost>) {
        for (post in posts) {
            val schedule = ScheduleParser.parse(post.text) ?: continue
            val date = schedule.date.toString()
            dao.upsertIfNewer(
                ScheduleEntity(date, post.id),
                schedule.queues.flatMap { (queue, intervals) ->
                    intervals.map { IntervalEntity(date, queue.toString(), it.startMinute, it.endMinute) }
                },
            )
        }
    }

    private fun ScheduleWithIntervals.toDomain() = Schedule(
        date = LocalDate.parse(schedule.date),
        queues = intervals
            .mapNotNull { e -> Queue.parse(e.queue)?.let { it to Interval(e.startMinute, e.endMinute) } }
            .groupBy({ it.first }, { it.second })
            .mapValues { (_, list) -> list.sortedBy { it.startMinute } },
    )
}
```

```kotlin
object WidgetStateLoader {
    suspend fun load(context: Context): StatusText {
        val c = context.container
        val now = ZonedDateTime.now(KyivTime.ZONE)
        val today = now.toLocalDate()
        val lastSync = c.settings.lastSyncAt.first()
        val status = PowerStatusCalculator.calculate(
            today = c.repository.get(today),
            tomorrow = c.repository.get(today.plusDays(1)),
            queue = c.settings.queue.first(),
            now = now,
            hasSynced = lastSync != null,
        )
        WidgetRefreshScheduler.scheduleNext(context, status, now)
        return StatusFormatter.format(status, now, lastSync)
    }
}

/** Re-renders the widget from cache at the next status change or next midnight, whichever is first. */
object WidgetRefreshScheduler {
    private const val SLACK_MS = 5_000L

    fun scheduleNext(context: Context, status: PowerStatus, now: ZonedDateTime) {
        val nextMidnight = now.toLocalDate().plusDays(1).atStartOfDay(KyivTime.ZONE)
        val change = when (status) {
            is PowerStatus.On -> status.nextOffAt
            is PowerStatus.Off -> status.nextOnAt
            else -> null
        }
        val at = listOfNotNull(change, nextMidnight).minOf { it.toInstant() }
        val pi = PendingIntent.getBroadcast(
            context,
            0,
            Intent(context, WidgetRefreshReceiver::class.java),
            PendingIntent.FLAG_UPDATE_CURRENT or PendingIntent.FLAG_IMMUTABLE,
        )
        context.getSystemService(AlarmManager::class.java)
            .setAndAllowWhileIdle(AlarmManager.RTC, at.toEpochMilli() + SLACK_MS, pi)
    }
}

                PowerWidget().updateAll(context)

                pending.finish()
            }
        }
    }
```

```kotlin
package ua.echecker.sync

import android.content.Context
import android.util.Log
import androidx.glance.appwidget.updateAll
import androidx.work.BackoffPolicy
import androidx.work.Constraints
import androidx.work.CoroutineWorker
import androidx.work.ExistingPeriodicWorkPolicy
import androidx.work.ExistingWorkPolicy
import androidx.work.NetworkType
import androidx.work.OneTimeWorkRequestBuilder
import androidx.work.PeriodicWorkRequestBuilder
import androidx.work.WorkInfo
import androidx.work.WorkManager
import androidx.work.WorkerParameters
import kotlinx.coroutines.CancellationException
import kotlinx.coroutines.flow.Flow
import kotlinx.coroutines.flow.first
import kotlinx.coroutines.flow.map
import ua.echecker.container
import ua.echecker.widget.PowerWidget
import java.time.Duration
import java.time.Instant
import java.util.concurrent.TimeUnit

class SyncWorker(context: Context, params: WorkerParameters) : CoroutineWorker(context, params) {
    override suspend fun doWork(): Result {
        val c = applicationContext.container
        return try {
            if (!c.settings.backfillDone.first()) {
                c.repository.backfill(since = Instant.now().minus(Duration.ofDays(30)))
                c.settings.markBackfillDone()
            } else {
                c.repository.sync()
            }
            c.settings.markSynced(Instant.now())
            PowerWidget().updateAll(applicationContext)
            Result.success()
        } catch (e: CancellationException) {
            throw e
        } catch (e: Exception) {
            Log.w(TAG, "Sync failed (attempt $runAttemptCount)", e)
            if (runAttemptCount < 3) Result.retry() else Result.failure()
        }
    }

    companion object {
        const val TAG = "SyncWorker"
    }
}

object SyncScheduler {
    private const val PERIODIC = "sync-periodic"
    private const val NOW = "sync-now"

    private val network = Constraints.Builder().setRequiredNetworkType(NetworkType.CONNECTED).build()

    fun schedulePeriodic(context: Context) {
        val request = PeriodicWorkRequestBuilder<SyncWorker>(30, TimeUnit.MINUTES)
            .setConstraints(network)
            .setBackoffCriteria(BackoffPolicy.EXPONENTIAL, 1, TimeUnit.MINUTES)
            .build()
        WorkManager.getInstance(context)
            .enqueueUniquePeriodicWork(PERIODIC, ExistingPeriodicWorkPolicy.KEEP, request)
    }

    fun syncNow(context: Context) {
        val request = OneTimeWorkRequestBuilder<SyncWorker>().setConstraints(network).build()
        WorkManager.getInstance(context).enqueueUniqueWork(NOW, ExistingWorkPolicy.REPLACE, request)
    }

    fun observeSyncNowRunning(context: Context): Flow<Boolean> =
        WorkManager.getInstance(context).getWorkInfosForUniqueWorkFlow(NOW).map { infos ->
            infos.any { it.state == WorkInfo.State.RUNNING || it.state == WorkInfo.State.ENQUEUED }
        }
}
```

```kotlin
import ua.echecker.domain.Schedule
import ua.echecker.sync.SyncScheduler
import ua.echecker.widget.PowerWidget
import java.time.Instant
import java.time.LocalDate

data class DaySchedule(val date: LocalDate, val intervals: List<Interval>)

data class MainUiState(
    val queue: Queue? = null,
    val today: DaySchedule? = null,
    val tomorrow: DaySchedule? = null,
    val history: List<DaySchedule> = emptyList(),
    val lastSyncAt: Instant? = null,
    val refreshing: Boolean = false,
)

class MainViewModel(app: Application) : AndroidViewModel(app) {
    private val c = app.container
    private val today = LocalDate.now(KyivTime.ZONE)

    val state: StateFlow<MainUiState> = combine(
        c.settings.queue,
        c.repository.observeRange(today.minusDays(30), today.plusDays(1)),
        c.settings.lastSyncAt,
        SyncScheduler.observeSyncNowRunning(app),
    ) { queue, schedules, lastSync, refreshing ->
        fun Schedule.forQueue() = DaySchedule(date, queue?.let { intervalsFor(it) }.orEmpty())
        val byDate = schedules.associateBy { it.date }
        MainUiState(
            queue = queue,
            today = byDate[today]?.forQueue(),
            tomorrow = byDate[today.plusDays(1)]?.forQueue(),
            history = schedules.filter { it.date < today }.map { it.forQueue() },
            lastSyncAt = lastSync,
            refreshing = refreshing,
        )
    }.stateIn(viewModelScope, SharingStarted.WhileSubscribed(5_000), MainUiState())

    fun selectQueue(q: Queue) {
        viewModelScope.launch {
            c.settings.setQueue(q)
            PowerWidget().updateAll(getApplication())
        }
    }

    fun refresh() {
        SyncScheduler.syncNow(getApplication())
    }
}
```

## Known limitations (accepted)

- Widget re-render alarm is inexact (`setAndAllowWhileIdle`) — may lag a few minutes in Doze; no exact-alarm permission requested.
- After reboot the alarm is lost until the next periodic sync (≤ 30 min) re-renders the widget.
- `MainViewModel` computes "today" once; if the screen stays open past midnight it shows yesterday until reopened.
- Telegram markup changes break `ChannelFetcher.parseHtml` — the fixture test documents the expected markup.
